A Node is generic — set its type in the Inspector. A Waypoint node is a routing point (small dot) that a link’s route must pass through. Road: drag from cell to neighbouring cell (diagonals too) — only cells you drag between are connected. Erase removes the top layer first: node, upgrades, roads, bridge, feature, terrain — or pick layers in the Erase row under the map to remove only those. Link two linked nodes again to unlink them, or use × in a node’s Inspector.

Structure presets

Selecting a preset arms the Node tool pre-filled with a type, values and structure class.

Garrison units

Drag onto a selected node's garrison, or click it while a node is selected. Each becomes its own assignment (faction, sortie, patrol, delivery).

Loss criteria

Prototype-only. Each group is a set of critical-asset nodes with a rule: lose if any is captured, or only once all are. A faction is knocked out when any one of its groups triggers.

Faction relations

Per-map relations. Reset replaces them with the defaults set in the Factions view.

Links

Pick "Link two nodes" (Place tab), then click two placed nodes. A link is an intended route: its path is found across the terrain (cheaper on roads, blocked by unbridged water and other nodes). Unlinked nodes never get a route. Use Waypoint nodes to force a route through a point.
